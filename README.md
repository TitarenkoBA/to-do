# 🌀 Ритм

Офлайн-PWA для продуктивного дня: задачи, напоминания, будильники, календарь, заметки, дневник, трекер привычек и помодоро-таймер. Работает без интернета, без регистрации и без сервера: все данные (включая фото, видео и голосовые) хранятся в IndexedDB на устройстве.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm start` | dev-сервер на http://localhost:4200 (без service worker) |
| `npm run build` | прод-сборка в `dist/to-do/browser` + генерация `sw.js` |
| `npm run preview` | сборка + локальный сервер http://localhost:4300 (PWA, офлайн, установка) |
| `npm run deploy` | **сборка и публикация на GitHub Pages одной командой** |
| `npm test` | юнит-тесты (парсер естественного языка, повторы, .ics) |
| `npm run icons` | перегенерировать иконки в `public/icons` |

## Деплой на GitHub Pages

1. Создай пустой репозиторий на https://github.com/new (например, `ritm`).
2. Первый раз укажи его адрес:
   ```bash
   npm run deploy -- https://github.com/<логин>/ritm.git
   ```
3. Дальше просто `npm run deploy`.

Скрипт сам создаст git-репозиторий (если его нет), запомнит `origin`, соберёт проект и принудительно запушит сборку в ветку `gh-pages`. Приложение будет доступно по адресу `https://<логин>.github.io/ritm/`. Если после первого деплоя страница отдаёт 404, включи Pages в настройках репозитория: Settings → Pages → Branch: `gh-pages` / `(root)`.

Маршрутизация через `#`, а `<base href="./">` относительный, поэтому приложение работает в любом подкаталоге без доп. настроек.

## Возможности

- **Задачи**: списки, приоритеты, теги, подзадачи, повторы (ежедневно / по будням / еженедельно / ежемесячно / ежегодно), вложения. Свайп вправо — выполнить, влево — удалить (с отменой).
- **Быстрый ввод на русском**: «позвонить маме завтра в 19:00 #семья !1», «планёрка каждый пн в 10», «выключить духовку через 30 минут», «отчёт 25.12», «@работа». Распознанное видно сразу, пока печатаешь.
- **Напоминания**: системные уведомления, звук и вибрация. Звуки синтезируются через WebAudio, файлов нет.
- **Календарь**: месяц с точками задач и настроением дня, повторяющиеся задачи, экспорт/импорт `.ics`. Кнопка «В календарь» у задачи открывает системный календарь телефона.
- **Будильники**: дни недели, мелодии, отложить; быстрый таймер; «Ночной режим» с большими часами, экран при этом не гаснет (Wake Lock).
- **Заметки**: цвета, закрепление, архив, чек-листы, теги, фото / видео / голосовые, поиск.
- **Дневник**: настроение, вопросы-подсказки, медиа, график настроения за 30 дней, «Год в пикселях», «Год назад в этот день».
- **Привычки**: цель в день (например, 8 стаканов воды), дни недели, напоминание, серии 🔥, рекорд, тепловая карта.
- **Помодоро**: фокус и перерывы, привязка к задаче, автостарт, статистика за неделю, режим погружения, фоновые шумы (дождь, океан, бурый, розовый и белый шум).
- **Ещё**: поиск и команды (`Ctrl+K`), горячие клавиши (`N`: новая задача, `F`: фокус), светлая и тёмная тема, выбор акцентного цвета, резервная копия в JSON вместе с медиа, конфетти 🎉.

## Ограничения браузера

Веб-приложение не может само разбудить телефон, когда оно полностью закрыто. Поэтому напоминания и будильники срабатывают, пока Ритм открыт или свёрнут в фоне. Для надёжного подъёма есть «Ночной режим», а для системных напоминаний задачи можно экспортировать в календарь (`.ics`). Если браузер поддерживает Notification Triggers, уведомления планируются и при закрытом приложении.

## Структура

```
src/app/core     — данные (IndexedDB), NLP-парсер, напоминания, звук, помодоро, ICS/бэкап, PWA
src/app/shared   — иконки, шторки, задачи, медиа (камера/диктофон/просмотр), поиск
src/app/pages    — экраны: сегодня, задачи, календарь, заметки, дневник, привычки, фокус, будильники, настройки
scripts/         — генерация sw.js, превью-сервер, деплой, иконки
```
